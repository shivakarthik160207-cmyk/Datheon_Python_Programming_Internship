# Datheon Python Programming Internship

## Task 1 - Hangman Word Guessing Game

A terminal-based Hangman word guessing game developed using Python.

## Features

- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect attempts
- ASCII Hangman gallows
- Tracks previously guessed letters
- Prevents duplicate guesses from reducing attempts
- Input validation
- Win and game-over conditions

## Technologies Used

- Python 3
- random module

## How to Run

```bash
python Task_1_Hangman/hangman.py
